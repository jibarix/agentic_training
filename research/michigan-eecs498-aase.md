# EECS498 — Applied Agentic Software Engineering (University of Michigan, Fall 2026)

- **URL(s):** https://eecs498-aase.github.io/ (overview), https://eecs498-aase.github.io/syllabus.html (syllabus and weekly schedule), https://eecs498-aase.github.io/faq.html, https://eecs498-aase.github.io/podcast/ ; materials repo https://github.com/eecs498-aase/materials ; GitHub org https://github.com/eecs498-aase
- **Instructors:** Marcus Darden (instructor). GSIs: Rafe Symonds and Zilin Wang. IA: Rushil Kagithala.
- **Level/prereqs:** EECS 498-016, a 4-credit upper-level CS technical elective. Prereqs: EECS 281 and EECS 201, or ULCS standing, or instructor permission. Language: Python, plus the shell and git. No AI/ML background or prior AI coding-tool experience assumed (FAQ).
- **Format:** In person, Aug 31 - Dec 11, 2026. Lectures Tue + Thu 3:00-4:30 PM (28 lectures), one 2-hour lab a week in two identical sections (12 lab sessions, Lab00-Lab11), and three supervised evening hackathons. No exams. All projects are individual. Three phases: Apply (L01-L06, Lab00-Lab01), Analyze (L07-L14, Lab03-Lab04), Create (L15-L28, Lab05-Lab11). Tools: Aider with a small local model (qwen3.5:4b or 9b via Ollama or llama.cpp, or any OpenAI-compatible endpoint) in Apply; from Lab03, Codex on gpt-6-luna through the U-M GPT Toolkit, working in a private copy of Aider's codebase; Lab05 on the Codex app-server.
- **Public materials:** Slides (PDF, PPTX and Slidev Markdown source with speaker notes) for L01-L11 and L13-L19, and for Lab00, Lab01, Lab03, Lab04 and Lab05 (Lab02 as PDF only), in the materials repo. Demo codebases for L01, L03 and L04, and the Elephant-Goldfish Model (EGM) as five installable Agent Skills. AI-generated companion podcast episodes (seven so far, L01-L05) with transcripts. Lectures are recorded (CAEN capture and Zoom), but no public recording links were found. Assignment repositories are delivered privately to enrolled students.
- **License:** Not stated for the site or the materials repo (no LICENSE file). The `aider-ollama` setup repo is MIT.

**Overview.** The course teaches software engineering with AI coding agents in three phases: use one, take it apart, build on one. In Apply, students drive Aider with a small local model, first through sixteen guided lessons and then to specify and build their own terminal pair-programmer (conversation, context management, edit formats, diff-and-approve edits, commits and undo, YAML endpoint configuration) against an OpenAI-compatible Chat Completions contract. Diagnosis rests on the "Big Three" (context, model, prompt) and on specification-driven development. Analyze opens production harnesses (Aider, Codex, Claude Code): the request and stream on the wire, the tool loop, stop conditions, approvals and guardrails, skills, shell, MCP and browser tools, prompt injection, always-on assistants and subagents. In project P2, students use Codex to extend a private copy of Aider with a skills loader, a model-driven tool loop, a shell tool behind approval rules and a stdio MCP client, each designed first with Dave Rensin's Elephant-Goldfish Model (a design doc reviewed by a fresh-context session). Create builds on an existing harness. It covers compaction and prompt caching, agent memory, knowledge bases, multiple model providers, and coordinator/thread setups like Claude Code Projects, with Lab05 introducing the Codex app-server. The course grades understanding over output: students must be able to explain every line they submit.
