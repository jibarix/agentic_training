# CS329T — Trustworthy Machine Learning: Building and Evaluating Agentic Systems (Stanford University, Fall 2025)

**Overview.** CS329T is a project-based course on building agentic AI applications on foundation models and on evaluating them so they can be improved step by step. The schedule opens with LLM background, prompting and RAG, then moves to agent foundations and the course's main evaluation idea: checking an agent's goals, plans and actions (the "Agent GPA", Goal-Plan-Action alignment). The middle of the term is mostly guest talks: systematic agent evaluation and refining LLM judges, MCP and writing tool descriptions, data curation and RL for agents, GEPA (reflective prompt evolution with DSPy), and agent security (attacks, guardrails, red-teaming benchmarks). About half the meetings are student project presentations. The single homework has students trace and evaluate a LangGraph multi-agent web-research system in TruLens, annotate failure modes by hand, compare those labels with LLM-judge metrics, and then improve the agent. For an agent builder, the main draw is the evaluation-first workflow (traces, human annotation, judge validation) and the reading list on agent evaluation, RL environments and agent security.

## Codebases & tools referenced

- TruLens (open-source LLM app tracing and evaluation): https://github.com/truera/trulens . HW1 uses `run_dashboard()`, human feedback on traces, LLM-judge metrics and `session.get_leaderboard()`
- LangGraph: agentic concepts page https://langchain-ai.github.io/langgraph/concepts/agentic_concepts/ ; the main-branch notebook pins `langgraph==0.5.4`
- Tavily search API and the OpenAI API (HW1 needs both keys; the handout estimates under $2.00 in OpenAI cost)
- Substitute HW1 notebook (main branch): https://github.com/truera/trulens/blob/main/examples/experimental/web-search-agent-human-annotation-flow.ipynb . It uses `trulens`, `trulens-apps-langgraph`, `trulens-providers-openai`, `langchain_tavily`, `langchain_openai` and `langchain_experimental`, with nodes planner, executor, web_researcher, chart_generator, chart_summarizer and synthesizer. Judge metrics: Plan Quality, Plan Adherence, Execution Efficiency, Logical Consistency, plus the RAG triad (Groundedness, Answer Relevance, Context Relevance)
- DeepLearning.AI short course "Building and Evaluating Data Agents": https://www.deeplearning.ai/short-courses/building-and-evaluating-data-agents/
- Model Context Protocol: https://modelcontextprotocol.io/docs/getting-started/intro
- DSPy https://dspy.ai/ and GEPA https://github.com/gepa-ai/gepa
- Together cookbook, Open Deep Research: https://github.com/togethercomputer/together-cookbook/blob/main/Agents/Together_Open_Deep_Research_CookBook.ipynb
- Agent benchmarks/environments: SWE-bench, SWE-smith, ARE/GAIA2, OSWorld, Terminal-Bench https://www.tbench.ai/ , Gray Swan Arena https://app.grayswan.ai/arena
- AI coding assistants (Cursor, Claude Code) are explicitly allowed and encouraged for HW1
