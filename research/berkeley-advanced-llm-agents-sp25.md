# CS294/194-280 — Advanced Large Language Model Agents (UC Berkeley, Spring 2025)

- **URL(s):** https://rdi.berkeley.edu/adv-llm-agents/sp25 (Berkeley for-credit course page), https://agenticai-learning.org/sp25 (MOOC page with the same syllabus, quizzes, certificate tiers, labs). Lab materials: https://drive.google.com/drive/folders/1DsXvOqfvFs4yBc2ZrLuOCXAFXBb5q1kg. Competition: https://rdi.berkeley.edu/agentx/
- **Instructors:** Dawn Song (Professor, UC Berkeley); guest co-instructors Xinyun Chen (Google DeepMind) and Kaiyu Yang (Meta FAIR). Course staff listed: Alex Pan, Tara Pande, Ashwin Dara, Jason Yan.
- **Level/prereqs:** Upper-division undergraduate (CS194-280, class 33840) and graduate (CS294-280, class 33841), variable units (1-4). Prereq: ML/DL background, e.g., CS182, CS188 or CS189 (strongly encouraged). The MOOC lists no prerequisites and points to the Fall 2024 LLM Agents MOOC as background.
- **Course format:** Weekly guest lectures, Mon 4-6pm PT (two sessions at 10am-noon), Anthro/Art Building 160, livestreamed on YouTube; in-person attendance expected for enrolled students. Berkeley grading depends on units: participation, reading summaries, quizzes, an article (1 unit), a lab (2+ units), and a project with proposal, milestone, poster, recording and report (2+ units; 3/4-unit students also graded on implementation, applications or research track). MOOC: 12 completion-graded quizzes (5 MCQs each), a ~500-word article, the Lean labs (Mastery tier), and the AgentX project (Ninja/Legendary tiers); all due May 31, 2025.
- **Public materials:** Slide PDFs and YouTube recordings for all 12 lectures, plus an intro deck; optional readings per lecture; quiz forms and a quiz archive Google Doc; Lab 1 and Lab 2 instruction files plus two ZIPs in a public Google Drive folder.
- **License:** None stated on either site or in the lab instruction files.
- **Past offering:** Predecessor: CS294/194-196 Large Language Model Agents, Fall 2024 (MOOC at https://llmagents-learning.org/f24).

**Overview.** The course is a guest-lecture series on where LLM agent research went after the Fall 2024 course: reasoning and post-training (inference-time techniques, iterative preference optimization, open recipes like Tulu 3), language-agent memory and planning, coding agents and vulnerability detection, multimodal web and computer-use agents, and then a four-lecture block on formal mathematics and verification (AlphaProof, autoformalization, LeanDojo-style theorem proving, abstraction discovery). It ends with agent safety and security. The hands-on part ties into the math block: the labs have students write Lean 4 problems with formal specs, then build an LLM agent workflow (planning, generation, Lean-checked feedback, optional RAG) that writes verified Lean code and proofs. For an agent builder, Lab 2 is the main draw, a small but real verify-and-retry agent loop with a compiler as the judge.
