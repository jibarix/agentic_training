- **URLs:** https://www.cmu-agents.com/ (schedule at https://www.cmu-agents.com/#/schedule, assignments at https://www.cmu-agents.com/#/assignments); GitHub org https://github.com/cmu-agents; YouTube playlist "CMU 11-768, AI Agents: Fall 2026" https://www.youtube.com/playlist?list=PLSN0qpDfUvTM (the page resolved to that title, but the ID looks short; verify it)

Private tests, grading, and Modal/LLM credits are for enrolled students only.
- **License:** n/a (none seen).

**Overview.** Neubig's announcement gives the goal: students learn to build an agent scaffold, write evals for it, and train an agentic LLM with RL, with theory balanced against modern frameworks and best practices. The course has six blocks. Capabilities covers tool use, context management, skills and memory, and planning. Domains covers coding, GUI, and deep research. Training covers SFT, RL, and RL systems. Then come safety and frameworks, interaction (multi-agent and human-agent), and search (critics, tree search). The material is grounded in production harnesses rather than toy agents. Readings include real source code (OpenHands, Codex, OpenCode, Hermes Agent), the MCP spec, and KV-cache pricing pages. The three assignments form one pipeline (harness, then evaluation, then RL training), and the course ends with a team research project.

## Assignments / Projects

| Name | What you build | Skills | Starter code URL | Tags |
|---|---|---|---|---|
| A1: Build an Agent Harness (due Sep 14; 10%) | A domain-agnostic ReAct `Agent` base class: prompt construction, tool-call loop, step limit, model-generated context compaction. On top of it, a `CodeAgent` (terminal/message tools, skill loader with progressive disclosure via `invoke_skill`) that fixes a chess-app bug and solves SWE-bench `django__django-15368` with and without compaction. Then a `ChessAgent` (play_move, stateless simulate_move, sandboxed run_python, chess skill) plus an observation A/B experiment. Uses Modal sandboxes, an OpenAI-compatible LLM (default DeepSeek-V4-Flash), uv, and pytest. 100-pt rubric. | ReAct loops, tool dispatch, sandboxing, skills, context compaction, token accounting | https://github.com/cmu-agents/assignment-1 (handout: https://github.com/cmu-agents/assignment-1/blob/main/ASSIGNMENT.md); chess app: https://github.com/cmu-agents/chess-app | ARCH, TOOL, CODE |
| A2: Evaluating a Data-Visualization Agent (due Oct 1; 15%) | A `validate(run)` LLM-as-judge validator that flags four error families (execution_failure, wrong_data, wrong_chart, hard_to_read), scored by per-family and macro MCC against human labels. Students author 5+ new tasks, run 3 fixed agents (15+ runs), human-label the runs, and package the tasks as Harbor environments with deterministic tests, a reference solution, and two mutants. The judge is fixed to Qwen3-VL-30B on Modal. Grading: report 40%, private-set MCC 30%, quiz 20%, code 10%. | Eval design, LLM-as-judge, human labeling, verifier robustness, benchmark packaging | https://github.com/cmu-agents/assignment-2 | EVAL |
| A3: Agentic RL Training, "scottyrl" (due Oct 29; 15%) | Fill in TODOs for REINFORCE/GRPO advantages, trajectory to masked token sequences, grouped rollouts, a sync trainer, and an async producer-consumer GRPO trainer. Tasks: Number Search (sync and async), ablations (group size 2, stale-4 async with and without importance weighting), and async GRPO on TextCraft-Synth. The final adapter is exported to Hugging Face. Uses Tinker 0.24.0 with a SkyRL Tinker server on Modal and vLLM/SGLang. | Policy-gradient RL for multi-turn agents, async RL systems, ablation methodology | https://github.com/cmu-agents/assignment-3 | TRAIN |
