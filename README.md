# Learning to Build Agentic Systems

Three documents and a draft book by J. A. Arroyo on designing and building agentic systems, compiled from public university courses and published guides.

| Folder | Document |
|---|---|
| `guide/` | *Learning to Build Agentic Systems*: an instructional compilation guide built from public university courses (`agentic_guide.pdf`). |
| `design_process/` | *Agentic System Design Process*: nine phases from problem framing to production, each with its evidence and a "done when" gate (`design_process.pdf`). |
| `task_screening/` | *Screening Tasks for Agentic Automation*: a worksheet for deciding whether a task needs an agent, with worked examples (`task_screening.pdf`). |
| `bigbook/` | *The Big Book of Agentic AI Engineering* (draft): one engineering pattern per chapter, each with working code and an experiment on a local model (`bigbook.pdf`). Results are reported for Chapters 1–4; the later experiments are not yet complete. See its README for the detailed status. |
| `research/` | The course tables the guide is built from. |

The four document folders have READMEs; the first three include their rebuild command. The Big Book's LaTeX source is not published, so its README explains the companion code instead. The documents state their own sources, limits and use of AI tools.
